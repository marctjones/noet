# Fonts

**IBM Plex** (Sans, Mono, Serif) by IBM, used under the **SIL Open Font License 1.1**
(see OFL.txt). https://github.com/IBM/plex

Chrome uses IBM Plex Sans; the raw-source editor uses IBM Plex Mono. (Serif is
bundled for future use.) The sred WYSIWYG editor renders via cosmic-text and is
not affected by these.
