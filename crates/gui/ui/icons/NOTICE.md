# Icon assets

The SVG icons in this directory are from **Lucide** (https://lucide.dev),
an open-source icon toolkit (a fork of Feather Icons), used under the **ISC License**.

`currentColor` was replaced with `#000` so Slint can tint them via `Image.colorize`.
